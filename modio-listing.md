<h2>Restricted Areas</h2>
<p>Other plugins call IsRestricted() and Subscribe. RestrictedAreas answers whether the local player is in a restricted area. This plugin draws no window.</p>

<h2>Data Protection</h2>
<p>RestrictedAreas reads the local player's tile to answer whether that tile is restricted. It keeps listener callbacks in memory for the session. It does not write that tile. Game information is not stored between sessions. This information is not transmitted outside of the plugin under any circumstances.</p>
